EASIEST WAY TO GET THE ACTUAL .JAR

1. Create a new GitHub repository.
2. Upload EVERYTHING in this folder to the repository root.
3. Open the repository -> Actions.
4. Click "Build Chaos Vote Mod".
5. Run workflow.
6. Wait for it to finish.
7. Open the completed workflow run.
8. Scroll to Artifacts.
9. Download "chaos-vote-jar".
10. Inside that download, take the .jar file and upload it directly to ChunkArc's /mods folder.

The project targets Minecraft 1.21.1, Fabric, and Java 21.
You still need Fabric API in the server's /mods folder.
